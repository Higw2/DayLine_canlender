# 时序日程验收标准

目标环境：Ubuntu 24.04 LTS、GNOME X11、GTK 4.14、libadwaita 1.5。所有验收使用 `/tmp` 中的隔离数据目录，不读取或修改用户现有日程和桌面设置。

## 放行条件

- 自动化测试全部通过，无未处理异常、GTK critical 或 traceback。
- P0/P1 条目全部通过；P2 视觉条目无明显影响使用的问题。
- 重启应用、关闭主窗口、切换到“显示桌面”后，核心状态和提醒行为仍符合预期。

## 验证方法

1. 静态检查入口、应用 ID、数据库路径覆盖方式和退出/关闭语义。
2. 用 `pytest` 执行存储、提醒状态机、跨日查询和单实例相关测试。
3. 在 `DISPLAY=:1` 的真实 GNOME X11 会话中启动应用；为隔离运行设置临时 `HOME`/XDG 数据目录或应用支持的测试数据库路径。
4. 用 GTK 信号或 XTest 驱动创建、编辑、删除、稍后提醒、完成、日期切换及关闭窗口。
5. 用 Pillow `ImageGrab` 获取原始截图；用 `xwininfo`、`xprop` 检查窗口存在性、EWMH 类型与状态。
6. 对同一数据库进行进程级重启，检查持久化、重复提醒、单实例及后台提醒。

验收记录应列出执行环境、命令、通过/失败编号、截图或日志位置，以及可稳定复现的缺陷步骤。任何因窗口管理器限制而无法自动断言的条目，必须给出实际会话截图和对应 X11 属性，不能仅凭代码推断通过。
