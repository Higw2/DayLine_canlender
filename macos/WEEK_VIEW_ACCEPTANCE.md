# 一周横轴时间线（2026-11-16）

## 行为

- 横轴固定周一至周日，纵轴 00:00–24:00。表头显示星期及日期，左侧只有一组时间刻度，七列共用纵向滚动。
- 在相应日期的列内拖拽新建事件；保留 15 分钟吸附、边缘调整、Esc 取消、双击及按钮编辑、删除确认和 Command 单击完成。
- 跨午夜事件在对应日期列显示裁切片段，只允许调整真实端点。片段操作绑定原事件 ID，一周统计不会重复计数。
- 上一周、下一周分别移动七天；本周及返回今天重置为今天所在周；侧栏选日期与周表头选择保持同步。
- 新建事件默认日期遵从当前选择，拖拽创建遵从起始列。数据库查询覆盖整周及从上周跨入、向下周跨出的事件，不改动原有数据库格式。
- 周列随可用宽度自适应，重叠较多或字体较大时提供横向滚动；为常驻滚动条预留空间，避免遮住周日按钮。
- 实机截图发现表头中的弹性占位占用过多高度，已固定为随字体缩放的 48pt，并增加容器高度回归检查。
